# Проект: aiganym — сайт-приглашение на ужин

Личная страница-письмо для Айганым от Ерназа (GitHub: yernazyergali, Telegram: @yyernaz).
Статический сайт без сборки: `index.html`, `style.css`, `script.js`. Деплой через GitHub Pages
(Actions, `.github/workflows/pages.yml`) при каждом пуше в `main`.
Адрес: https://yernazyergali.github.io/aiganym/

## Как устроена страница
1. `#gate` — экран «Включи звук», кнопка «Я готова» запускает музыку (`song.mp3`, зациклена, плавное нарастание).
2. `#envelope` — конверт: открывается клапан, письмо выезжает, конверт уходит.
3. `#letter` — письмо: вступление (про 7 октября), 11 блоков `<article>` «фото/видео + подпись», финальный блок `#invite`.
4. `#invite` — «Наш ужин остаётся в силе?» Четверг · 19:00 · Renee. Кнопка «Да, конечно, в силе» открывает Telegram с готовым сообщением. Под ней «А если нет, то всё ок.»

## Где что менять
- Тексты и подписи: `index.html`.
- Ник в Telegram и текст сообщения: `script.js` (`TELEGRAM_USERNAME`, функция `#yes`). Если меняешь день/время/место в `index.html` (блок `.details`), поменяй и текст сообщения.
- Цвета, шрифты, анимации: `style.css` (переменные в `:root`).
- Фото: `img/*.jpg` (ширина до ~1000 px, JPEG ~80%). Видео: `videos/*.mp4`, автозапуск без звука, пауза вне экрана.
- Музыка: `song.mp3` в корне. Лучше ~128 kbps. Чтобы петля была без щелчка, сделай кроссфейд конца и начала.

## Полезные команды
Сжать видео с iPhone:
`ffmpeg -i in.mov -vf "scale=720:-2,fps=30" -c:v libx264 -crf 27 -pix_fmt yuv420p -c:a aac -b:a 96k -movflags +faststart videos/name.mp4`
Сжать фото: `magick in.jpg -resize 1000x -quality 82 img/name.jpg`
Деплой: `git add -A && git commit -m "..." && git push` → через 1–2 минуты обновится сайт.

## Правила
- Страница личная и закрыта от поисковиков (`noindex`), не добавлять аналитику и трекеры.
- Подписи к фото писать только по тому, что видно в кадре, без выдуманных фактов.
- Тон: тёплый, уважительный, без давления. Текст на русском.
- Не хранить в репозитории токены и пароли.
